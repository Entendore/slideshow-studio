# Slideshow Studio examples

This folder ships ready-made slideshows. Load one with
File > Import example, or via File > Import slides…

getting-started.txt     Text-script deck: # starts a slide, ~ adds narration
product-launch.md       The same script idea written as Markdown
team-update.html        Import from a web page (headings split the slides)
solar-power.pptx        PowerPoint import, including speaker notes
quantum-computing.pdf   PDF import: pages become background plates
demo-tour.slideshow     A full project: motion, overlays and narration set

# What each one shows

- Text scripts (.txt / .md) are the fastest way to draft a deck by hand.
- The HTML file keeps bold, italics, colours and lists as rich text.
- The PPTX file imports its speaker notes as the narration text.
- The PDF import wipes the original text and re-renders it editable.
- demo-tour.slideshow opens with Ken Burns motion, a progress bar and
  slide-number overlays already enabled - just export it.

# Where exports go

Exported MP4 / MP3 / WAV / HTML files land in the output folder next to
this one (File > Open output folder). Change the destination inside the
export dialog any time; the studio remembers your last folder.
